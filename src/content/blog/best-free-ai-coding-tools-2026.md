"Free" in AI tooling often means "free for 14 days" or "free until you hit the limit in day one." This list covers only tools with genuinely usable free tiers — the ones worth bookmarking before you put in a credit card.

## 1. OpenCode (BYOK) — Completely Free If You Have API Access

**What's free:** The entire OpenCode application, forever. You pay only for API tokens.

[OpenCode](/tools/opencode/) is the most genuinely free option if you already have Anthropic, OpenAI, or Google API access. You install OpenCode (open source, no subscription), configure your API key, and get a full-featured terminal coding agent at $0/month.

The actual cost depends on how much you use it:
- Light use (occasional asks, small edits): ~$2–5/month in API costs
- Moderate use (daily coding assistant): ~$10–20/month
- Heavy agentic use: $25+/month

If you have unused API credits from a previous project, OpenCode is a genuinely zero-cost AI coding tool.

**Limitations of the free tier:** None — you have full OpenCode functionality. The only cost is API tokens.

## 2. Cursor Free — Limited but Real

**What's free:** 2,000 completions and 50 premium requests per month.

[Cursor's](/tools/cursor/) free tier gives you a taste of the Pro experience. The completion limit resets monthly, and 50 premium requests is genuinely enough to evaluate the tool. After that, you're on the slower free model tier (still useful, just not frontier models).

For developers evaluating AI IDEs before committing, Cursor's free tier is the most polished onboarding experience. The IDE itself is fully functional — you're just limited on the AI side.

**Limitations:** 50 premium requests/month feels tight for real work. Most developers who like Cursor upgrade to Pro within a week.

## 3. GitHub Copilot Free — 2,000 Completions/Month

**What's free:** 2,000 code completions and 50 chat messages per month.

[GitHub Copilot's](/tools/github-copilot/) free tier (launched in late 2024) gives VS Code and JetBrains users meaningful AI assistance at no cost. 2,000 completions is a real amount of AI help for developers doing focused work.

The free tier uses the same underlying models as paid — no downgrade in quality, just quantity limits. For developers who want AI suggestions integrated directly into their existing VS Code workflow without switching IDEs, Copilot Free is the most frictionless option on this list.

**Limitations:** 50 chat messages/month is restrictive. Great for completions, not for conversational coding.

## 4. Windsurf Free — Light Daily Quota

**What's free:** AI completions and a light daily quota of Cascade agent interactions.

[Windsurf's](/tools/windsurf/) free tier is genuinely usable for light AI coding sessions. The Cascade agent is accessible, Tab completions are unlimited, and the IDE is fully functional. The "light daily quota" means you'll hit the ceiling if you try to run full agentic workflows, but for developers trying the tool or doing occasional AI assists, it works.

The IDE itself is a strong free product even without the AI features — it's a polished VS Code fork with good performance.

**Limitations:** The premium AI interaction quota is too low for daily development. Think of it as a sustained trial, not a real free tier.

## 5. Ollama + OpenCode — Fully Local, Truly Free

**What's free:** Local LLM inference with no API costs.

[Ollama](https://ollama.ai) runs open-weight models locally: Codestral, Qwen 2.5 Coder, DeepSeek Coder, Llama 3.1. Combined with OpenCode's local model support, this creates a completely free AI coding stack — no subscription, no API costs.

Performance depends on your hardware. On an M2 MacBook Pro or a PC with a modern GPU, 7B–14B parameter models are fast enough for meaningful coding assistance. Complex multi-step reasoning tasks won't match Claude Sonnet 4.6, but for autocomplete, simple refactors, and documentation generation, local models are surprisingly capable.

**Limitations:** Hardware requirements (8GB+ VRAM recommended for decent performance). Model quality below frontier models for complex reasoning. No cloud or mobile access.

## 6. Claude.ai Free — Conversational AI Coding Help

**What's free:** Limited daily messages with Claude Haiku 4.5 or Sonnet 4.6.

Claude.ai's free tier isn't a coding IDE, but it's free access to Anthropic's models for coding questions. Paste code, ask questions, get refactoring suggestions — the free tier is limited in message count but useful for developers who want AI assistance without a subscription.

For actual code editing in your project files, you need Claude Code or a tool with file system access. But for architecture questions, debugging help, or code reviews of small snippets, Claude free covers the basics.

**Limitations:** No file system access, no agent capabilities, message limits.

## The Honest Verdict

The genuinely free options come down to: OpenCode BYOK (free app, you pay API) or Ollama (local inference, no API costs). Everything else is a limited trial of a paid product.

GitHub Copilot Free comes closest to a real free tier — 2,000 completions/month is meaningful and the VS Code integration is native. For inline suggestions and occasional chat, it's worth installing whether or not you pay.

If budget is the constraint, start with Copilot Free for VS Code completions + OpenCode with a few dollars of Anthropic API credit for agentic tasks. You'd spend under $10/month for a capable AI coding setup.
