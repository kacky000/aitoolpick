# Void Pricing 2026: Is the Open-Source Cursor Alternative Free?

Void is an open-source AI code editor positioned as a transparent alternative to Cursor — same VS Code foundation, AI chat and edits, but with your data staying under your control. The headline question in 2026: is it actually free? Here's the full breakdown.

## Pricing at a Glance

| Plan | Cost | What You Get | Best For |
|------|------|--------------|----------|
| Void Editor | $0 | Full open-source editor | Everyone |
| Model Usage | Pay provider | Your own API keys | Solo devs, teams |
| Local Models | $0 | Run models on your machine | Privacy-first users |

## How Void's Pricing Works

Void itself is free and open source — there is no Void subscription. You supply model access, either by connecting API keys (paying OpenAI, Anthropic, Google, or others directly) or by running local models. So your total cost is whatever your chosen model provider charges, and nothing to Void.

## Void Editor ($0)

The editor is completely free, including AI chat, inline edits, and codebase-aware features. Because it's open source, you can inspect exactly how your code and prompts are handled — a key selling point for privacy-conscious teams.

**Best for:** Anyone wanting a free, transparent AI editor.

## Model Usage (Pay Provider)

Void routes AI requests through your own keys, so you pay per token to the model provider. Costs scale with usage and your model choice, and there's no markup from Void.

**Best for:** Developers who already hold API keys.

## Local Models ($0)

Void can connect to locally hosted models (via Ollama and similar), meaning zero ongoing cost and full offline privacy — ideal for sensitive codebases.

**Best for:** Privacy-first and offline development.

## How Void Compares on Price

| Tool | Entry Price | Strength |
|------|------------|----------|
| Void | $0 + BYOK | Fully open source, private |
| Cursor Pro | ~$20/mo | Most polished experience |
| Cline | Free + BYOK | VS Code extension |
| Zed | Free tier | Fast native editor |

Void's differentiator is transparency: open source plus the option of local models means your code never has to leave your machine.

## Is Void Worth It?

### Void fits when:
- You want an open-source Cursor alternative at no editor cost
- Privacy and local models matter to you
- You already pay for model APIs

### A paid editor fits when:
- You want bundled model access and zero setup
- Polish and support outweigh cost

## Tips to Optimize Void Costs

1. **Try local models first** — zero token cost for routine work
2. **Bring cheaper API models** for bulk edits, premium for hard tasks
3. **Monitor provider usage** — the only real bill comes from your keys
4. **Contribute or self-host** — it's open source, so no lock-in

## Bottom Line

Void's pricing is simple: the editor is free and open source, and you pay only your model provider — or nothing at all with local models. For privacy-focused developers who don't mind a little setup, it's one of the cheapest ways to get AI-native editing. Try it free before comparing to paid rivals.
