Cursor's pricing changed completely in October 2026. SpaceX closed its $60 billion acquisition of Anysphere (Cursor's parent company) on August 14, 2026 — the largest acquisition of a venture-backed startup on record — and collapsed Cursor, Grok, and X Premium into a single five-tier subscription called **The X Subscription**.

If you were on the old Hobby, Pro, Pro+, Ultra, or Teams plans, those are now legacy. Here's what the new structure looks like.

## The New X Subscription Plans

| Plan | Price | What You Get |
|------|-------|--------------|
| **Free** | $0 | Daily Grok access, basic Cursor Agent credits, standard X |
| **Plus** | $8/month | Weekly AI pool (Grok models only), all X features |
| **Premium** | $30/month | 4× Plus usage, third-party models (Claude, GPT-4o) at API list price |
| **Super** | $100/month | 15× Plus usage, priority model access at peak times |
| **Ultra** | $200/month | 50× Plus usage, earliest new feature access |

Teams seats start at **$30/user/month**.

## What Actually Changed

**Plus is cheaper now — but restricted.** The old Pro was $20/month and included third-party models like [Claude](/tools/claude/). The new Plus at $8 only runs Grok inside Cursor. If you want Claude or GPT-4o in Cursor, you need Premium ($30) or higher, and those models are billed at API list price on top of the subscription.

**Usage is pooled weekly, not monthly.** Each plan gives you a weekly AI pool shared across Grok (via X), Cursor's coding agents, and any other X apps. When you exhaust the pool, you can top up with prepaid credit or wait for the weekly reset on Sunday.

**Third-party models now cost extra.** On Premium and above, [GitHub Copilot](/tools/github-copilot/)-style models and Claude/GPT calls are billed at the provider's API rate from your prepaid credit balance, not from a flat allowance. Heavy [Claude](/tools/claude/) Opus usage can add $20–40/month on top of the subscription.

Most Pro users will see a price increase if they want equivalent model access. The Teams tier actually gets cheaper.

## Who Should Pick Which Plan

**Free**: Occasional coding help, mainly Grok-powered. Good for learning or small side projects.

**Plus ($8)**: Budget-conscious developers comfortable using Grok as their primary coding model. Grok has improved significantly in 2026 but still trails Claude Sonnet for complex refactors.

**Premium ($30)**: The new default for professional developers. You get 4× the weekly pool and can use Claude, GPT-4o, and other frontier models — you just pay per token. If your AI usage is moderate (under ~$10/month in model costs), this is the best value.

**Super ($100)**: Power users running Cursor in agentic mode all day. The 15× pool means you rarely hit limits. Compare to [Devin](/tools/devin/) at $500+/month for context.

**Ultra ($200)**: AI-first developers building multiple projects simultaneously and who want early access to SpaceX's upcoming AI features. Same price as before, significantly more included usage.

## The SpaceX Factor

The acquisition has divided the [AI coding](/category/ai-coding/) community. On the positive side, SpaceX brings hardware (Starlink compute), distribution (X's 600M+ users), and financial stability. On the negative side:

- **Enterprise hesitancy**: Some companies are pausing Cursor procurement reviews until SpaceX clarifies data handling under its new privacy terms
- **Model dependency**: Grok-only plans reduce optionality compared to the old multi-model approach
- **Lock-in**: Usage pools are tied to The X Subscription, making it harder to mix Cursor with a separate Grok or X plan

[Windsurf](/blog/windsurf-vs-cursor-2026), [GitHub Copilot](/blog/github-copilot-pricing-2026), and [Claude Code](/blog/claude-code-beginners-guide-2026) all gained users in the weeks after the acquisition announcement.

## How to Compare Total Cost

For a developer using Claude Sonnet ~$10 in API calls per month on top of Premium:

- **Premium ($30) + ~$10 model costs = ~$40/month**
- Old Pro ($20, included Claude access): The new equivalent actually costs more

Use this rough formula: **Premium price + expected model API spend = real monthly cost**.

## Bottom Line

The X Subscription is a bold bet that Grok will close the gap with Claude and GPT-4o by 2027. If you're comfortable with Grok, **Plus at $8** is genuinely cheap. If you need the best models, expect to pay **$30–50/month** with API costs factored in — up from the old $20 Pro.
